MedAssist là gì

Ứng dụng di động (Flutter) tra cứu thông tin thuốc cho người Việt: tìm theo tên, nhận diện hộp thuốc bằng OCR chạy trên máy, hỏi đáp với trợ lý AI luôn trích dẫn nguồn, lưu hồ sơ sức khoẻ và nhắc uống thuốc. Backend FastAPI cung cấp tài khoản, dữ liệu thuốc, lịch sử và agent. Thông tin trong app chỉ mang tính tham khảo, không thay thế bác sĩ hoặc dược sĩ.

Bài toán

  • Người dân khó hiểu tờ hướng dẫn thuốc (công dụng, tác dụng phụ, tương tác).
  • Chatbot AI thông thường có thể bịa thông tin y khoa; MedAssist chỉ trả lời từ nguồn đã nạp, kèm trích dẫn, và từ chối khi không có căn cứ.
  • Dữ liệu sức khoẻ rất nhạy cảm: ảnh, thuốc đang dùng, lịch sử không được gửi đi tuỳ tiện.

Luồng một câu hỏi trong chat

câu hỏi → lọc ngoài phạm vi / prompt injection ──► từ chối nếu vi phạm
        → planner chọn công cụ → công cụ chạy trên dữ liệu thuốc → trích dẫn
        → (nếu bật LLM thật) LLM diễn đạt lại → verify_grounding
              đạt  → dùng câu của LLM       không đạt → dùng câu trích nguyên văn
        → gắn thuốc đang dùng + disclaimer → phát SSE: tool_call · citation · token · done
Nguyên tắc: ports & adapters, contract-first, offline-first. Đổi backend chỉ sửa core/providers.dart, có test canh. LLM không quyết định có trả lời hay không, cũng không chọn công cụ.

Khoảng hở đã biết

  • SQLite cục bộ và cache chưa mã hoá; CSDL server chưa mã hoá khi lưu.
  • Access token còn hiệu lực tối đa 15 phút sau khi xoá tài khoản (dữ liệu đã bị xoá nên không đọc được gì).
  • Retention mặc định tắt; chưa có lịch dọn refresh token hết hạn.
  • Chưa có báo lỗi crash.

Lỗi thật đã tìm và sửa trong quá trình làm

  • R8 báo thiếu lớp ML Kit → thêm -dontwarn trong proguard-rules.pro.
  • Bản release crash nhắc thuốc do Gson TypeToken → thêm luật giữ lớp.
  • Splash trắng không nhìn thấy → đổi nền splash sang màu teal.
  • Retrieval kéo nhầm thuốc khác → neo theo tên thuốc.
  • Adapter LLM nhận nội dung không phải chuỗi → từ chối (test bắt được).
  • Nhắc thuốc không đặt được: tên múi giờ tự đặt ("device") làm Java ném ZoneRulesException → đổi sang UTC+07:00 (chỉ lộ khi chạy máy ảo).
  • MCP không chạy được thật: tiến trình MCP không nhận MEDASSIST_DB (DB rỗng) và code đọc isError trong khi SDK dùng is_error → sửa cả hai, thêm test chạy tiến trình con.

Chạy và demo

Cách nhanh nhất (máy ảo)

# cửa sổ 1 — server (khoá giả, chỉ localhost, tự nạp 10 thuốc mẫu)
.\tools\demo_server.ps1          # LLM mock (ổn định)
.\tools\demo_server.ps1 -Llm     # LLM thật chạy trên máy (Ollama)

# cửa sổ 2 — máy ảo + app bản dev (mặc định không build lại)
.\tools\demo_app.ps1             # thêm -Build khi vừa sửa code Dart

Tài khoản demo (dữ liệu giả): tên đăng nhập demo, mật khẩu Demo@12345678. Ô đăng nhập dùng tên đăng nhập, không dùng email.

Chạy trên điện thoại thật

adb reverse tcp:8000 tcp:8000
flutter run --flavor dev --dart-define=APP_FLAVOR=dev --dart-define=API_BASE_URL=http://127.0.0.1:8000

Kiểm thử

flutter analyze ; flutter test
cd server\medassist-core ; python -m pytest -q ; python eval.py

Build bản phát hành

flutter build appbundle --release --flavor prod --dart-define=APP_FLAVOR=prod --dart-define=API_BASE_URL=https://ten-server-https-cua-ban
Lưu ý RAM: máy 15,6 GB, chạy cùng lúc Ollama + máy ảo + Gradle dễ hết bộ nhớ ("paging file is too small"). Trước giờ demo hãy đóng bớt Chrome/IDE và đừng build lại.
Câu hỏi nên dùng khi demo: "Panadol có tác dụng phụ gì", "Panadol công dụng gì". Câu hỏi liều dùng hoặc tương tác sẽ bị từ chối — đó là thiết kế an toàn với dữ liệu mẫu.
