  • BACKEND = core (FastAPI) hoặc flask (server cũ); ANALYZER = remote | ondevice | hybrid.
  • Bản release bắt buộc HTTPS.

Bảo vệ

  • Phân quyền theo user_id ở mọi endpoint lịch sử và agent; truy vấn tham số hoá.
  • Giới hạn tần suất đăng nhập/xoá tài khoản (429 + Retry-After).
  • Audit log không chứa user_id, username hay route; access log của uvicorn đã tắt vì chứa từ khoá tìm thuốc.
  • Server không khởi động nếu MEDASSIST_SECRET_KEY thiếu hoặc ngắn hơn 32 byte.

AI — truy hồi có trích dẫn, không bịa

Nói thẳng khi thuyết trình: mặc định mô hình sinh chữ là MockLLMProvider (chỉ ghép lại đoạn đã truy hồi, kèm mã trích dẫn). Đã có thêm adapter LLM thật chạy trên máy (Ollama), bật bằng MEDASSIST_LLM=ollama, đã chạy thử thật với model qwen2.5:3b (cài ở D:\ollama, trả lời khoảng 0,3–1,7 giây khi model đã nạp). Mô hình học máy thật đã chạy được là ML Kit OCR. Xem docs/LLM_LOCAL.md.
Vì sao Ollama mà không phải ChatGPT/Claude đám mây: Ollama chạy ngay trên máy, adapter chỉ nhận địa chỉ 127.0.0.1 (không proxy, không redirect) nên dữ liệu sức khoẻ không rời máy. LLM đám mây chỉ được nối sau khi có đồng ý trong UI + khử định danh + ghi PRIVACY. Câu LLM sinh ra vẫn phải qua verify_grounding; không đạt thì quay về câu trả lời trích nguyên văn.

Luồng xử lý một câu hỏi

câu hỏi
  → lọc chủ đề ngoài phạm vi (chẩn đoán, kê đơn, liều dùng, tương tác, cấp cứu…)  → từ chối: out_of_scope
  → phát hiện prompt injection                                                   → từ chối: out_of_scope
  → truy hồi bằng chứng (BM25 + neo tên thuốc)    → rỗng                          → từ chối: no_evidence
  → dựng prompt (nguồn = dữ liệu, được escape)
  → LLMProvider.generate()   (mock, tất định, offline)
  → verify_grounding(): mỗi câu phải bám vào một đoạn đã trích dẫn               → từ chối: unsupported_claim
  → trả lời kèm trích dẫn [R1], [R2]… và disclaimer

Postman

Dự án gốc không dùng Postman. Tài liệu API do FastAPI tự sinh (/docs, openapi.json). Tôi đã tạo thêm một collection Postman từ openapi.json để bạn thử API trên máy: docs/postman/MedAssist-Local.postman_collection.json (5 thư mục, 19 request, mỗi request có test kiểm tra mã trạng thái).

Cách chạy

  1. Chạy server: .\tools\demo_server.ps1 (khoá giả, chỉ localhost, tự nạp 10 thuốc mẫu).
  2. Mở Postman → Import → chọn file collection ở trên.
  3. Biến collection đã có sẵn: baseUrl = http://127.0.0.1:8000, username = demo, password = Demo@12345678 (dữ liệu giả).
  4. Chạy theo thứ tự: 1. Health → 2. Auth › Đăng nhập (hoặc Đăng ký nếu chưa có) → các thư mục còn lại. Đăng nhập tự lưu accessToken và refreshToken vào biến collection.
  5. Chạy cả bộ: nút Run collection. Để cuối cùng 2 request Đăng xuất và Xoá tài khoản nếu muốn giữ tài khoản demo.

Lưu ý

  • Chat (SSE) trả luồng sự kiện; xem dần ở tab Response.
  • Xoá một bản ghi lịch sử: đổi số 1 trong đường dẫn thành id lấy từ request "Danh sách lịch sử".
  • Không dán token thật hay email thật vào collection; collection này chỉ dành cho dữ liệu giả.
  • Không cần Postman: mở http://127.0.0.1:8000/docs để thử API bằng Swagger UI.
